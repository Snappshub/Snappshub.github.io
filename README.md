# SN Apps Hub — Public Website

**Repository role:** Public-facing static website for https://snappshub.github.io/

## Contents
- Website entry point and public pages
- Public styles, scripts, logos and other static assets
- Public app catalogue data required by the website
- Search-engine files such as robots.txt and sitemap.xml

## Excluded
Admin dashboard source, backend/API code, private configuration, credentials, deployment secrets, and internal backups must stay out of this repository.

## Publishing
GitHub Pages should publish the website from the main branch (root) after Pages settings are confirmed in repository Settings → Pages.
